# Disease Prediction ML

A machine learning project that predicts diseases using patient-related health features.

## Project Overview

This project uses Machine Learning classification algorithms to predict whether a person is likely to have a particular disease based on the given input data.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Machine Learning Models

* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Feature and Target Selection
4. Train-Test Split
5. Feature Scaling
6. Model Training
7. Model Prediction
8. Model Evaluation
9. Model Comparison

## Evaluation Metrics

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* Confusion Matrix

## Dataset

The project uses a dataset containing health-related features and a target variable for disease prediction.
